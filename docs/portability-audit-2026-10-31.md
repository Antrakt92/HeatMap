# Проверка совместимости HeatMap — 31 октября 2026

Проверены изменения Windows ARM64, связь с прежним x64 backend, запуск,
сохранение настроек, обнаружение датчиков, отказоустойчивость и остаточный код.
Найденные ошибки исправлены локально; публикация в GitHub не выполнялась.

## Исправления

- ARM отключает управление вентиляторами только во время работы. Сохранение
  положения/вида окна больше не перезаписывает исходные четыре флага управления
  вентиляторами из конфигурации x64. Редактирование калибровки CPU на ARM закрыто.
- Прямой запуск `launch.py` на x64 передаёт управление существующему launcher.
  Batch продолжает x64-путь только при специальном коде 20, а не при произвольной
  ошибке ARM. Проверены пробелы, апострофы, амперсанды и Unicode в путях.
- Загрузка GPU сопоставляется с LUID и физическим индексом адаптера, от которого
  получена частота. Неоднозначные данные разных GPU не смешиваются.
- Сбой PDH не скрывает независимо полученную частоту WDDM. Счётчики повторно
  открываются через 30 секунд. WinAPI привязывается один раз, а адаптеры заново
  обнаруживаются и их дескрипторы закрываются при каждом опросе.
- Разбор ACPI учитывает относительные ссылки и вложенные пространства имён;
  смешанные и неоднозначные связи не становятся ложным датчиком GPU. Кэш профиля
  версии 4 проверяется, чтение ограничено по размеру, запись атомарна. Невозможность
  сохранить кэш не отменяет успешное обнаружение.
- Удалены неиспользуемый помощник разбора, импорт и устаревшие отображения
  нормального статуса backend. Версия psutil читается из общих constraints,
  вместо второго независимого значения в native preflight.

## Проверки и результаты

- Полный набор: **1218 тестов — OK**, включая 16 регрессий этого аудита.
- `compileall`, `setup.py --verify`, `setup.py --preflight`, `git diff --check` — OK.
- Статический проход 133 Python-файлов: нет повторных определений в одной области
  видимости (пары property getter/setter учитываются отдельно). В новых runtime
  модулях не обнаружены неиспользуемые импорты. Это не доказательство отсутствия
  любого недостижимого кода, особенно в динамических WinAPI/CLR путях.
- Интеграция launcher на настоящем Windows cmd/PowerShell: выбор интерпретатора,
  предупреждения, ошибки, отсутствие Python, пути со специальными символами,
  коды native-маршрута 0/1/35. UAC endpoint заменён тестовым; реального повышения
  прав эта проверка не выполняла. Временные файлы удалены.
- Интеграция планировщика: XML временного задания зарегистрирован и прочитан,
  классифицирован как `safe_current`, LeastPrivilege, priority 6. Задание не
  запускалось и удалено; существующий автозапуск не менялся.
- Интеграция опроса диска: зависший дочерний процесс завершён за 2,24 секунды,
  оставшихся процессов нет; реальная ёмкость и связь C: с физическим диском получены.
- Живое окно на Snapdragon: SoC около 37–38 °C, GPU около 36–37 °C, текущая
  частота GPU 550 MHz, температура UFS 35 °C, заполнение C: 41,2%. Проверены
  отсутствие fan workers и постоянных служебных подписей, обрезка имени диска
  перед зарезервированными температурой и процентом. Показания меняются во времени.
- Исходные DLL, манифесты и версии constraints не изменялись.

## Границы совместимости

На ARM используются доступные Windows интерфейсы; на x64 сохраняется прежний
LHM/драйверный путь и его проверки. Датчики выбираются по данным оборудования,
а недоступные или неоднозначные значения не подменяются догадками. RPM на этом
ноутбуке проверенными интерфейсами не предоставляется.

Старый x64 компьютер физически не проверялся. Тесты не заменяют проверку его
реальных температур, LHM/драйвера и управления вентиляторами. Перезагрузка/вход,
сон/пробуждение, игровая нагрузка, шум вентиляторов и несколько мониторов остаются
ручными проверками. Файлы аппаратной калибровки следует хранить на исходном ПК.
Одинаковая доступность датчиков на любом произвольном компьютере не гарантируется.

## Повторная проверка на домашнем Windows x64 ПК

На домашнем ПК проверена та же ARM64-ветка через прежний LHM backend. Выбор
backend вернул x64. Локальное окружение первоначально не соответствовало уже
существующим constraints: pythonnet 3.1.0 и pycparser 3.0 заменены на закреплённые
3.2.1 и 3.12. Остальные зависимости, DLL, драйверы и настройки охлаждения не
обновлялись. После обновления прошли 1218 тестов, compileall, pip check,
preflight, проверка DLL и синхронизации манифестов. Проверка происхождения
лицензий прошла для 23 пакетов.

Локальные Windows integration checks прошли для launcher, временного задания
планировщика, desktop/PiP, диалогов и bounded volume probes. Проверка задания
повторена из основной копии с её venv: в отдельной рабочей копии первоначально
был выбран системный Python без psutil. Временное задание не запускалось и
удалено; существующее задание автозапуска сохранено.

Повышенная проверка CPU smoke прошла. Три независимых read-only LHM снимка
в штатном режиме совместного мониторинга с Gigabyte Control Center дали CPU
64–65 °C, RX 7900 XT Core 44 °C, Hotspot 44–45 °C и память GPU 60 °C;
частоты, загрузка, RAM и оба CPU fan RPM читались. Получены ёмкость и physical
mapping C:/D:/E:/F:, а также температуры всех четырёх накопителей: 32–42 °C.
Обычный запуск через существующее задание Windows зарегистрировал новую
версию процесса. Свежие отчёты: case active, GPU standby на сохранённой кривой
драйвера. Штатное закрытие подтвердило выход процесса и возврат корпусных
вентиляторов материнской плате без ошибок восстановления.

Эта проверка подтверждает запуск и реальные датчики данного x64 ПК. Она не
заменяет визуальную проверку физического окна, игровую нагрузку, сон/пробуждение,
перезагрузку и несколько мониторов. Локальные доказательства сохранены в
`%LOCALAPPDATA%/HeatMap/portability-*-20261031.json`; реальные отчёты и настройки
в репозиторий не добавлены.
